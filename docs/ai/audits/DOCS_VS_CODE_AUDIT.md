## 3. Explicit classification of the four required claim categories

- Full coverage ("100% de los puntos de venta") → **CONTRADICTION**. README.md/PLAN.md's mission statement makes an unqualified 100% claim; PLAN.md's own F8 gate documents a sealed 94.3% national figure with explicit residual gaps, and PROGRESO.md's 2026-06-23 self-audit found the underlying dealer census inflated approximately 2.9x with an actual servable dealer count of 18,994.
- Real-time updates ("tiempo real") → **ASPIRATIONAL**. The scheduler architecture is a 15-minute polling heartbeat driving per-source intervals that default to 168 hours (weekly), tuned to 24 hours (daily) for long-tail DealerProbe. Legitimate periodic batch refresh, not real-time or streaming.
- Complete delta detection ("delta completo") → **PARTIAL**. The delta primitives (NEW/GONE/PRICE_CHANGE/KM_CHANGE/PHOTO_CHANGE, append-only history) are real, implemented, and DB-enforced, and an API delta endpoint exists. But the change-delta emitters are wired into roughly 26 of 47 (about 55%) top-level connector files, with the remainder deferred by the code's own documentation ("A4-phase-2"). GONE detection runs from exactly one real call site (pipeline/ops/health.py), not embedded per connector.
- Production readiness → **NO_VERIFIED**. This audit collected no runtime evidence of a working deployment, per the read-only mandate; no explicit "production-ready" claim was found in the four core docs (good hygiene). A concrete gap bearing on readiness was found: the browser-automation stack is commented out of requirements.txt, meaning the README Quickstart's 8-step bring-up does not install the dependency RUNBOOK.md's own architecture requires for STEALTH-tier connector escalation.

## 4. Modules touched by the claims above

- **pipeline/delta.py** — shared delta machinery (GONE reconciliation plus NEW/PRICE/KM/PHOTO change detection). Entrypoints: `reconcile_gone(conn, source_key, run_started_at, ...)`, `emit_gone_events(conn, vehicle_ulids)`, `diff_vehicle(old, new)` (pure function), `emit_change_deltas(conn, existing_snap, new_vehicles, keys)`. Error handling: explicit safety guards (max_gone_fraction cap, min_coverage gate). Tests: 7 dedicated test files exist; not executed this session.
- **services/api/main.py and services/api/routers/entities.py** — FastAPI app (`app = FastAPI(title='Cardeep API', version='0.2.0', ...)` at main.py line 114) with routers for ops/entities/geo/vehicles/platforms. `GET /entities/{cdp_code}/delta` (entities.py line 171) is the delta-serving endpoint.
- **pipeline/ops/scheduler.py** — "B2.2 Durable single-producer scheduler". Entrypoint: `heartbeat_tick` job every 15 minutes selecting DUE sources by comparing now() to last_ok/last_fail against harvest_interval_hours. Also runs silence_watchdog hourly and an INQUISITION_CADENCE_HOURS = 6 verdict-freshness scan.
