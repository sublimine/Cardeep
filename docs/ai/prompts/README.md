# Prompt Library

Los prompts están separados por función:

- `00_bootstrap/`: instalación y relleno de governance.
- `01_loops/`: loops controlados.
- `02_audits/`: auditorías estáticas.
- `03_rfc/`: RFCs críticos.
- `04_tests/`: tareas TEST_ONLY.
- `05_safe_patch/`: plantilla SAFE_PATCH.
- `06_review/`: revisión humana / revisión de diff.
- `07_scorecards/`: scorecards y release readiness.

Regla: no pegues todos los prompts a la vez. Usa uno por tarea.
